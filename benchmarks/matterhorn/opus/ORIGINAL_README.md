# 马特洪峰 Matterhorn —— Three.js 写实三维模型

纯前端、零构建：`python3 -m http.server 5197` 后打开 http://localhost:5197/ 。
可选参数：`?view=sunnegga|riffelsee|gornergrat|hornli|cervinia|northface|aerial&t=8.3`（当地时间，秋分）。

## 怎么做出来的
- **地形**：在 GPU 上按真实地理要素生成高度场（`src/geo.js`：峰顶为原点，经纬度换算成 km）。
  - 马特洪峰本体：Hörnli / Furggen / Lion / Zmutt 四条山脊用“沿脊距离→高程”剖面描述，四个壁面由相邻山脊按等落差线插值，再加壁面起伏与峰顶短脊。
  - 周边：约 60 段山脊折线（登特布兰奇—魏斯峰、布赖特峰—罗莎峰、Mischabel…）+ 18 条谷地/冰川（采尔马特谷、Gorner、Zmutt…）+ 域扭曲 + 沿坡向的冲沟侵蚀噪声 + 片麻岩层阶。
  - 4 级 LOD（峰体 2.5 m、湖区 2.3 m、区域 11 m、远景 117 m 纹素），网格按距离切换 1/2/4 步长，外层挖洞+裙边+边缘渐变无缝拼接。
- **光照**：真实太阳位置（纬度 45.98°、秋分、CEST）；高度场光线步进软阴影（含地球曲率）；地平线法 AO；Nishita 大气散射天空 LUT；按高度积分的空气透视。
- **材质**：固定世界尺度的法线/曲率（预计算）决定积雪、冲沟积雪、碎石、草甸、森林、冰川（中碛条带、裂隙、冰舌碎石）。
- **云**：峰顶背风面的体积旗云（顺风拉伸噪声）、远处积云、9 km 卷云。
- **利菲尔湖**：Reflector 实时倒影 + 波纹 + 菲涅尔；远处换成只反射天空的廉价水面。

## 验证
`npm run e2e`（需先启动服务）→ `docs/e2e-report.json` + `docs/screenshots/`。
29 项：真实地标高程（峰顶、霍恩利小屋、采尔马特、利菲尔湖、罗莎峰等 12 处）、太阳高度/方位、各机位帧率、昼夜画面差异、东壁/北壁受光、机位飞行、防穿地、面板控件、手机布局、无报错。

## 局限
地形是“地理驱动的程序化生成”，不是 DEM：主峰与各地标高程、相对位置对得上，但细部山形、冰川轮廓是合成的。登特埃朗峰、魏斯峰比真实低约 180 m（侵蚀削顶，在容差内）。
