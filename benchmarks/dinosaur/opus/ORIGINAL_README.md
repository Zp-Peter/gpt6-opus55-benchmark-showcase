# 像素小城 · 恐龙过境

Three.js 实时渲染的 3D 体素微缩城市动画：一座安静的小城 → 霸王龙从画外走入 → 踩扁街角小店、甩尾扫坏书店、低头撞塌公寓 → 从另一侧走出画面 → 镜头停在受损的城市上。约 62 秒，可暂停、可重播。

## 启动

```bash
npm install
npm run dev          # http://localhost:5193
```

打开页面、场景搭建完成（约 0.3 s）后自动播放。

| 操作 | 按钮 | 键盘 |
|---|---|---|
| 暂停 / 继续 | ❚❚ / ▶ | 空格 |
| 重新播放 | ↺ | R |
| 声音（默认关，程序合成） | 🔇 / 🔊 | M |

## 动画编排（实际时间）

| 阶段 | 时间 | 内容 |
|---|---|---|
| A 平静城市 | 0–4.5 s | 全景；车辆巡航，鸟停在屋顶 |
| B 入场 | 4.5–18 s | 远处第一声脚步：鸟群惊飞、车辆加速驶离。恐龙沿西侧公路走入（镜头缓慢转到侧面），在城边停下仰头张嘴低吼 |
| C 破坏 | 18–44 s | ① **踩踏**（21.2 s）：转向路边小店，重心左移，右腿高抬、停顿蓄力、重踩，压碎屋顶和招牌<br>② **甩尾**（34.6 s）：在路口先向右蓄势，再猛地左转，尾巴横扫街角书店的顶层露台和立面，碎块被扫到街上<br>③ **冲撞**（42 s）：北上后转向东北角公寓，后撤、压低、前冲，头肩撞进南立面，失去支撑的顶层和屋顶水箱随后塌落 |
| D 离场 | 44–55.5 s | 收回重心，右转上东侧公路，头、身体、腿、尾巴依次走出画面 |
| E 破坏之后 | 55.5–62 s | 镜头拉回全景，尘土散尽，废墟、倒下的红绿灯与路灯保留；显示“完” |

## 实现要点

**统一时间基准**：所有模拟（恐龙、镜头、车辆、鸟、碎块、尘土、音效提示）都以 1/120 s 固定步长推进同一条时间轴；随机数可重置。暂停即停止累积，重播从同一初始状态开始，所以每次结果逐块一致（e2e 中逐条比对）。

**体素渲染**（`src/voxel`）：统一 1 世界单位 = 1 体素。自写网格化器只生成外露面，并烘焙逐顶点 AO 与逐体素明度抖动；玻璃、金属、自发光分材质。地面用世界坐标体素颗粒着色，与模型质感一致。

**城市**（`src/city`）：3×3 街区、22 栋建筑（街角小店、坡顶联排、底商公寓、玻璃幕墙办公楼、钟楼市政厅、霓虹餐馆、加油站、锯齿屋顶仓库、露台书店、酒店、小屋），路灯、红绿灯、行道树、长椅、消防栓、停车位、公园喷泉等道具按类型实例化。

**恐龙**（`src/dino`）：体素霸王龙（盒状头骨、眉骨、黄眼、上下交错牙、可张合下颌、脖颈、条纹躯干、背脊鳞突、鸡腿形大腿、跖行小腿、三趾带爪脚、短前肢、7 段渐细尾巴）。
- 步态：支撑脚在世界坐标中锁定；按“落地时刻身体应在的位置”预测步点，误差过大才迈步，两脚不会同时离地；摆动轨迹有抬起—前摆—落地，落地时骨盆下沉、左右重心交替。
- 腿：两段解析 IK + 跖骨，膝盖朝前，抬腿越高膝盖越往上抬。
- 尾巴：带刚度的质点链，行走时沿走过的路径跟随，原地转身（甩尾）时才整条横扫；转弯时头部先转。

**破坏**（`src/destruction`）：建筑体素按“层高 × 6 体素、带锯齿边界”预切分成块。完好时整栋一个网格（剔除封闭室内面），第一次受损才换成分块网格。
- **接触驱动**：恐龙身上约 30 个碰撞球（脚、腿、躯干、头、颌、尾节）每步与完好块做体素级相交测试，只有真正碰到的块才会断裂，并记录接触点与部位。
- **三种响应**：脚向下踩 → 脚下的块被压扁、周边墙体向外摊倒；头/身体撞 → 沿冲撞方向推出（限速，落在楼前）；尾巴扫 → 沿尾巴运动方向横向扫落。
- **失去支撑**：每次断裂后做支撑分析（下方完好，或两侧都有落地支撑才能悬挑）；失稳的相连块组成整体，短暂停顿后向缺口倾斜下坠，落地时碎成单块并扬尘。
- **碎块物理**：自写的冲量刚体（角点接触、摩擦、睡眠）。碎块落在“地面 + 已静止碎块 + 仍直立体素的真实顶面”上，静止后写回高度场形成可辨认的废墟堆；支撑消失时连锁唤醒上面的碎块重新落定。小碎屑与尘团用实例化方块，数量有上限，到时缩小回收；主要废墟保留。

**镜头**（`src/stage.js`、`src/show/choreography.js`）：正交相机，三分之四俯视。关键帧平滑跟随，三处破坏各自小幅推近；入场到踩踏期间方位角缓慢从 34° 转到 8°（让抬腿和落脚呈侧面），甩尾前转回。只有重踩和冲撞有短促轻微震动。

## 验证

```bash
npm run dev                 # 另开终端
npm run e2e                 # 37 项检查，截图写入 docs/screenshots/，报告写入 docs/e2e-report.json
node tests/record.mjs       # 实时录制整段动画到 docs/dino-city.webm
```

e2e 在本机 Chrome（无头 + Metal GPU，1600×900）中跑两轮：第 1 轮确定性推进并逐项检查、截图；第 2 轮点击“重新播放”按钮后实时完整播放。检查内容包括：自动播放、暂停冻结与继续无跳变、限帧 12 fps 与 CPU 降速下的时间一致性、恐龙从画外进入/完全走出、只有三栋目标建筑受损且首次破坏落在对应接触帧和对应部位、每个断裂块都与碰撞球实际相交、坍塌只在失去支撑后发生、静止废墟无悬空无穿地、支撑脚零滑动、双脚不同时离地、落脚贴地、转向角速度、重播完全复位且两轮破坏日志逐条一致、帧率、窗口缩放、控制台无报错。

## 已知限制

- 碎块之间没有真正的刚体互碰，靠高度场叠放；碎块只从上方接触仍直立的结构（不做侧向碰撞），极少数情况下会擦过墙侧。
- 支撑脚落地后不会因为之后落下或被清走的碎块重新调整高度。
- 除三处编排的破坏外，恐龙腿脚还会真实碰倒沿途的两处红绿灯、一根路灯和一个垃圾桶；这是接触造成的附带效果，不是编排事件。
- 音效是程序合成的占位级别，默认静音；验证只确认了音频上下文正常启动，没有做主观试听。
- 录屏由浏览器 MediaRecorder 生成的 WebM（本机无 ffmpeg），部分播放器可能无法拖动进度条。
- 只在 macOS 上的 Chrome 中验证过；没有加入行人。
