# 小城，大访客

一个使用 Three.js 实时渲染的 60 秒体素微缩城市动画。页面加载后自动播放，提供暂停、继续和重新播放。

## 启动

需要 Node.js 20.19+ 或 22.12+。在本目录运行：

```sh
npm install
npm run dev
```

打开终端提示的本地网址，通常是 <http://127.0.0.1:5173/>。也可以运行 `npm run build`，然后在 `dist` 目录启动任意静态文件服务器；本交付已包含构建好的 `dist`。例如：

```sh
cd dist
python3 -m http.server 8000
```

打开 <http://127.0.0.1:8000/>。请通过本地服务器访问，避免直接打开 `file://` 时模块路径受浏览器限制。

## 动画内容

| 时间 | 场面 |
| --- | --- |
| 0–5 秒 | 平静街区，车辆行驶。 |
| 5–15 秒 | 恐龙从左侧底座延伸的道路步行进入。 |
| 18 秒 | 左脚踩碎沿街花店，留下压低的残墙。 |
| 28 秒 | 头肩撞击中层砖楼，局部楼层坍塌。 |
| 37 秒 | 转身甩尾，扫坏另一侧店面的立面。 |
| 40–52 秒 | 恐龙继续行走并从右侧退出画面。 |
| 52–60 秒 | 镜头停留在废墟和未受损街区。 |

三处建筑分别保有完整与残骸状态。破坏事件检查脚、头或尾端与对应建筑的距离；碎块使用确定性的受控轨迹落地，主要残骸保留。恐龙、汽车、粉尘、碎块、镜头和界面使用同一播放时间；重新播放会清理动态碎片与粉尘并复原建筑。

## 工程结构

- `src/city.js`：底座、道路、十栋建筑、车辆与街道设施。
- `src/dinosaur.js`：体素恐龙、关节尾巴、步态与接触点。
- `src/destruction.js`：三处接触验证、残骸与粉尘。
- `src/main.js`：灯光、相机、60 秒时间轴和播放控制。
- `src/kit.js`：颜色、几何构件与实例化辅助。

美术均为本工程程序化建模与绘制的简单招牌纹理，不依赖外部图片或在线字体。

## 验证与限制

已在本机浏览器完整观看两轮，其中一轮从“重新播放”开始；另进行了接触帧拍摄和暂停测试。`npm run build` 通过。暂停 2.2 秒后的截图与暂停前逐像素一致；完成后浏览器控制台无错误或警告。`01-city-before.png` 至 `07-aftermath.png` 包含实际浏览器截图。

破坏是针对这条固定路线编排的局部状态切换，不是通用刚体物理系统。角色的脚部是以路程驱动的近似支撑步态，急转弯时仍可能出现轻微滑移。暂未制作音效或录屏。横屏观看效果最佳。
